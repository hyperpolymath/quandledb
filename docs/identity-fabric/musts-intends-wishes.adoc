== Spine + cross-repo wiring

The ⊕ MUST cell is load-bearing: *equivalence-integrity*. The `a = a` problem is
the single thing QuandleDB and krl are unconditionally bound to, from opposite
ends — QuandleDB *computes, stores, and witnesses* it (wrapping Skein.jl); krl
*resolves with* it. QuandleDB is database-facing but the stack is *not*
"SQL-for-knots", and Skein is the engine (not the "Retrieve leg") — both
anti-framings are ruled out by the 2026-06-18 grounding pass (Skein.jl #20, merged).

Sibling repos' key concerns (keep in sync as crossover resolves): *krl* — the
resolution DSL surface (holds the duplicated crossover); *tangle* — TangleIR +
type-safety semantics; *Skein.jl* — the computational engine QuandleDB wraps;
*echo-types* — structured-loss theory + the identity-fabric framing
(Conway·Fichte / Bruner / Ricoeur); *KnotTheory.jl* — knot-theory mathematics library (Skein weak-dep);
*nextgen-typing* — type-theory coordination monorepo. See `../../AFFIRMATION.adoc`.
